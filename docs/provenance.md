# Source and asset provenance

> **TL;DR:** This release preserves the original owned game and teaching bank, extracts only its required files, and uses invented learners with a fresh public history. No personal backend configuration or saved progress is included.

The application began as an original personal learning game, developed with AI coding assistance. Its controller, adaptive engine, authored data, match-day skin, shared workbench stylesheet and original 34 tests form the extraction. The original storage module, surrounding personal pages, research/profile notes, analytics and Git history were excluded. Public documentation restates the useful design without personal circumstances.

The release retains every original target and adds the practice routes documented in [content notes](content.md). That page records dictionary references for the specific teaching corrections. It describes an original AI-assisted bank, not an independently validated curriculum or a licensed third-party curriculum.

Local/cloud storage components, the database ownership schema and integration tooling derive from [Math Workshop 1.0.0](https://github.com/jessecmaddox3/math-workshop/tree/67e44fb38bd1a4387d52cee86bfe2d3d02003215), also MIT licensed. They are adapted to a separate game identifier, database, curriculum and snapshot shape. There is no included account or shared backend.

The app's visual theme is original CSS using system fonts. The promotional banner was generated with ChatGPT from the [saved brief](hero-prompt.txt). It uses no personal photographs, people, real teams or third-party logos. Generation provenance metadata is retained.

The optional cloud SDK is bundled from the exact locked dependency versions. [License manifest](../licenses/npm/SOURCES.json), original notice files and generated [third-party notices](../public/THIRD_PARTY_NOTICES.txt) accompany the source and downloads. The application and authored teaching bank use the [MIT license](../LICENSE).
