# Contributing

Thanks for making this your own. Improvements, useful variations and teaching corrections are welcome.

Explain the concrete problem and resulting behavior, then run the relevant core and browser checks in the README. Use fictional learners, local-only fixtures and a disposable backend. Keep personal exports, accounts, credentials, host configuration and normal-browser state out of code, screenshots, issues and pull requests.

For content changes, retain useful targets where possible and cite a reliable source for a disputed explanation. Every mastered root needs a build and inference route. Do not claim an educational result that was not measured. See docs/content.md and docs/design.md for the current model.

General fixes belong in the reusable public engine. Personal configuration belongs in ignored local files or private backups. Contributions are offered under the project's MIT license; dependency notices retain their upstream terms.
