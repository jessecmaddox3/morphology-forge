# Reporting a security issue

Use GitHub's private vulnerability reporting for this repository. Include a minimal reproduction with fictional accounts and synthetic data. Do not post real learner exports, adult email addresses, tokens or host credentials in a public issue.

The default game is local. Optional cloud deployments are operated by their hosts with their own accounts and policies. The publishable client key is public configuration; secret/service-role keys must never be put in the browser. Refer to docs/cloud-setup.md for the ownership model and deployment checks.

Disconnecting ends this page's connection. It does not delete remote data or immediately revoke an already issued server token. Hosts handle retention and account deletion in their own backend administration.
